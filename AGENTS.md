# Population ethics laboratory

A solver-backed lab for Arrhenius-style impossibility theorems in population axiology. The
library (`src/population_ethics/`) checks finite formalizations. The research code (`research/`)
searches for proof skeletons, minimal cores and escapes, and compares them with known proofs.

## Where things live

- `docs/results.md`: results register, generated by `just docs`. Never edit it by hand.
- `docs/decisions.md`: formalization decisions (`D-NNN`). Read before changing how a principle,
  grid or witness is encoded. Supersede an entry instead of editing its decision.
- `docs/questions.md`: open conjectures and fidelity questions (`Q-NNN`).
- `docs/journal/`: dated turn reports. They are frozen: never edit one after its turn ends.
  Write the next turn's report as a new file.
- `corpus/literature.toml`: prior work, read status, hashes, and collision verdicts per result.
- `corpus/sources.toml`: translation authority for the frozen witnesses. Its hash enters `scan`
  provenance, so edit it only when a translation changes.
- `research/ledger.json`: one row per tested hypothesis, written by the phase scripts through
  `research.lab.record`.
- `research/known.py`: the known-skeleton catalogue and the known-ground matcher.
- `research/roles.toml`: principle id -> proof role, with the reason for each assignment.
- `research/canon.py`: exact (nauty) canonical forms of skeletons at the motif (L0), role (L1),
  realization-contracted (L2) and principle levels.
- `research/realizations.toml`: lemma chains that realize derived-principle edges, with verified
  solver-found examples (`research/realizations.py`).
- `corpus/readings.toml`: cross-read source readings; the review-first gate (`research/readings.py`).
- `research/schema.py`: the 1999/2000 principle schema over numeric grids, instance generation
  and the independent audit.
- `research/ladder.py`: thesis-family principles (thesis, 2003, 2009) over an ordinal ladder of
  consecutive levels, with validated existential witnesses and an independent audit.
- `research/pN_*.py`: phase scripts; `just research` reruns them all. Phase 8 freezes and
  verifies every catalogued Arrhenius theorem after 1999.

## Rules

- Review first: a principle enters instance generation or the catalogue only after its reading
  passes the gate in D-010.
- A judgment that two principles or lemma chains realize the same abstract edge is recorded
  once, as data, with its source and reason (D-011). Do not re-judge it per session.
- Before adding a result to `known.CATALOGUE`, move its evidence to a phase that still verifies
  it. Phase 6 stops verifying catalogued cores.
- Every new result gets a ledger row. Every literature check updates `corpus/literature.toml`,
  including the `ledger` list of the collision it covers. Then run `just docs`.
- `just check` gates every commit.

## Gotchas

- The CLI parses `[[proof.nodes]]` but never checks them. Only the `arrhenius-2000/v1` builder
  yields proof evidence, so research certificates must be checked at script level with
  `check_proof`; `verify` does not see them.
- `problem_id` ignores the formalization id and experiment id. Two TOMLs with identical
  populations and formulas share a `problem_id`.
- `artifact_id` hashes the wall time, so reruns never match. Compare `problem_id`, `run_key` or
  `result_sha256` instead.
- `apply_candidate` `remove_groups` has no effect on fixed groups when run through the CLI.
- Never add MARCO blocking clauses to the constraint solver. Keep a separate map solver, as
  `research.lab.marco` does.
- Run mypy as `mypy src tests research` together, or `population_ethics` imports appear untyped.
- Every `uv run` reinstalls the editable package; `--quiet` hides the message, not the latency.
- `RankEngine.encode`, `schema.holds` and `p6_schema.formula_of` treat any shape other than S,
  N or W as the Addition shape I.
- Record small friction in `PAPERCUTS.md`.
